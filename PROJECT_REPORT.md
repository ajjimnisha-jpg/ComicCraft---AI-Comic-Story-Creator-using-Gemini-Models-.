# COMICCRAFT
## AI Comic Story Creator using Gemini Models

### 1. Abstract
ComicCraft is an artificial intelligence based Python application designed to generate comic stories from simple user ideas. The application uses a Gemini generative AI model to create a title, characters, scenes, dialogue and narration. A Tkinter graphical interface makes the system easy to use.

### 2. Introduction
Creating a comic normally requires planning characters, scenes and conversations. ComicCraft automates the creative writing stage by accepting a simple idea and asking a generative AI model to organize it into comic panels.

### 3. Objectives
- Generate creative comic stories.
- Reduce the time required for story planning.
- Generate structured panels automatically.
- Provide an easy Python GUI.
- Demonstrate practical use of generative AI.

### 4. Existing System
Traditional comic creation is mostly manual. The writer must develop the story, characters, dialogue and scenes separately.

### 5. Proposed System
ComicCraft accepts one story idea and sends a structured prompt to Gemini. The generated response is displayed in the application and can be saved as a text file.

### 6. Technologies
- Python
- Tkinter
- Google Gemini API
- google-genai library

### 7. Modules
1. User Input Module
2. Prompt Generation Module
3. Gemini AI Module
4. Comic Generation Module
5. Output and Save Module

### 8. System Flow
User Input → Prompt Creation → Gemini API → AI Response → Comic Display → Save

### 9. Advantages
- Simple interface
- Fast story generation
- Structured output
- Easy to extend
- Useful for creative projects

### 10. Limitations
- Requires an internet connection.
- Requires a valid Gemini API key.
- Generated content can vary between requests.
- The basic version generates text rather than illustrated comic images.

### 11. Future Enhancements
- AI-generated panel images
- Character image generation
- PDF comic export
- Voice narration
- Tamil and multilingual support
- Story history/database
- User authentication

### 12. Conclusion
ComicCraft demonstrates how Python and generative AI can be combined to create a practical creative application. The project converts a simple idea into a structured comic story and provides a foundation for future multimedia features.
